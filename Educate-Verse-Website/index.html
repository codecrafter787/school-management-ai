QR attendance and a gate that keeps records

Each student carries a QR code. A scan at the gate marks entry, records exit, and triggers a late-arrival alert to the parent when the student arrives after the cut-off time.

Attendance appears live in the admin panel, so class teachers and administrators see the same record.

About Educate Verse

Educate Verse is a school technology platform built only for schools. We do not build general software or serve other industries, so every feature is designed around how schools actually run.

Frequently asked questions

Is Educate Verse only for schools?

Yes. It is built for school owners, principals, administrators, teachers and parents.

Is AI usage included in the plan price?

No. Supported AI features are available on eligible plans, but AI, voice, SMS and WhatsApp usage is billed separately to the school.

How does billing work?

Plans are billed monthly. AI, voice, SMS and WhatsApp usage is billed separately to the school.

Can you build our school website?

Yes. We offer school-specific websites with admissions, notices, events and inquiry forms.

Does it work on mobile?

Yes. The admin panel is mobile-responsive.
